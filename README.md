# 棋譜暗記道場

将棋の定跡をツリーで管理し、盤上で指しながら暗記する練習サイトです（静的サイト / GitHub Pages）。

- `shogi.js`：駒の動き・指し手・KIF の読み書き
- `app.js`：画面（編集・暗記モード、定跡ツリー、コメント）。データはブラウザの localStorage に保存
- `tutorial.js`：6手の定跡を使った、操作対象の近くに指示を出すチュートリアル
- `library.html` / `library.js` / `library.css`：棋譜ファイルと次の一手ブックの一覧・棋譜の読み込み・バックアップ
- `default-files.js`：初回のサンプル棋譜と、3問入りの次の一手ブック
- `problems-store.js`：次の一手問題集の保存・検証・バックアップ合流
- `problem-editor.js`：棋譜の現在局面から、正解・問題文・解説・保存先を選んで問題を作成
- `problems.html` / `problems.js`：保存した問題集を開いて盤上で回答・編集
- `pieces.css`：文字だけ・丸文字コマ・明朝体コマ・本格コマの表示と設定プレビュー
- `fonts/`：駒の丸文字・筆文字に使う日本語フォントの小さなサブセットとライセンス
- サンプル定跡は `default-files.js` の `SAMPLE_KIF` にあります
- 定跡解説ページ（`joseki/`）は `tools/joseki-data.js` を編集して `node tools/build-joseki.js` で生成します（sitemap.xml も更新）

## 盤と駒

設定から駒を4種類選べます。文字だけは簡潔な一文字、丸文字コマは柔らかい丸文字、明朝体コマは明朝の一文字、本格コマは明るい木地と縦二文字の筆文字です。盤・持駒・設定見本で同じ表示を使い、後手の反転や成駒の表示にも対応します。

盤は榧・白木・緑・グレー（フェルト風）です。以前の「夜」はグレーへ、「明朝」は丸文字コマへ、「黒の駒」は本格コマへ引き継ぎます。棋譜のデータ形式は変わりません。

## チュートリアル

右上の「？」（使い方）を開き、「チュートリアルを始める」から任意で起動します。初回の案内や自動開始はありません。短い指示を、実際に操作するボタン・駒・コメント欄の近くに表示し、操作の進行に合わせてガイドと強調箇所が移ります。ガイドから途中終了・戻る・やり直しもできます。

教材は四間飛車の出だし6手と、6手目を三間飛車にした分岐です。実際の盤・ツリー・暗記・KIF処理を使い、次を順番に体験します。

1. 駒を動かす
2. 手順を戻す・進める
3. 分岐を追加する
4. ツリーで局面を選び、コメントを書く
5. 「答え」を使い、先手で2つの変化を暗記する
6. 後手で暗記する
7. 両方の手を暗記する
8. 設定でコメントを隠し、めくって確認する
9. 練習用棋譜をKIFに書き出す
10. 「読込」を押し、練習用KIFを通常と同じ読み込み画面で取り込む

体験中の棋譜はメモリ上だけで扱い、通常の棋譜保存やFirebase同期の対象にしません。終了時には元の棋譜と設定へ戻り、体験中に届いた同期更新があれば最新の保存内容を読み直します。「練習用の定跡を残して終了」を選んだ場合だけ、既存の棋譜を上書きせず追加します。「読込」は体験中だけ用意済みの練習ファイルを使い、終了後は通常のファイル選択へ戻ります。

成り・持ち駒の打ちはこの短い教材には含みません。Googleログインやバックアップの操作は「使い方」「ファイル」から利用できます。

## ファイル画面

「ファイル」では、棋譜ファイルと次の一手ブックを白い一覧エリアで管理します。名前と手数・変化数、問題数を表示し、行を選んで開けます。盤面ページでは棋譜の切り替えプルダウンをなくし、現在のファイル名とファイル画面へ戻るリンクを表示します。

ファイル画面の「棋譜を読み込む」からKIF/KIFUファイルを複数追加できます。UTF-8とShift-JISを読み分け、題名・コメント・分岐を保持します。同名ファイルは別名で追加し、既存の内容に上書きや自動合流はしません。盤面の「読込」では、従来どおり開いている棋譜に分岐を合流することもできます。

保存キーがまだない初回には、サンプル棋譜を1つと、解説付き3問入りの次の一手ブックを1つ用意します。既存データはそのまま使い、削除済みの空の一覧へサンプルを再追加しません。初期サンプルの保存で既存のクラウド同期状態を書き換えることもありません。

## 次の一手問題集

「ファイル」で「次の一手ブック」を新規作成できます。棋譜の編集画面で出題したい局面を開き、「この局面の次の一手問題を作る」から保存します。

- 正解は現在の局面の次の手（本線・分岐）から1つ選びます。次の手が未登録の局面では作成できません。
- 問題文は任意です。解説文は現在の局面のコメントが初期値になり、元のコメントを変えずに編集できます。
- 保存先の問題集を選べます。作成画面から新しい問題集を作ることもできます。
- 盤面・持ち駒・手番・正解候補をコピーして保存するため、元の棋譜を編集・削除しても問題は残ります。
- 保存した問題集は「ファイル」から開きます。盤上で答えると正解を判定し、正解または「答えを見る」の後に解説を表示します。
- 問題集は `kifu-anki-problems-v1` に独立して保存されます。すべてのバックアップ、復元、Googleログイン時の同期にも含まれます。従来の棋譜だけのバックアップも読み込めます。
- チュートリアル中の練習用棋譜からは問題を保存しません。

## 検証

依存パッケージのインストールは不要です。

```sh
node --check app.js
node --check tutorial.js
node --check problem-editor.js
node --check default-files.js
node --check library.js
node --check problems.js
node --check sync.js
node tools/test-tutorial.js
node tools/test-problems-store.js
node tools/test-problem-editor.js
node tools/test-problem-library.js
node tools/test-problem-sync.js
node tools/test-default-files.js
node tools/test-library-import.js
```
