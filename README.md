# 棋譜暗記道場

将棋の定跡をツリーで管理し、盤上で指しながら暗記する練習サイトです（静的サイト / GitHub Pages）。

- `shogi.js`：駒の動き・指し手・KIF の読み書き
- `app.js`：画面（編集・暗記モード、定跡ツリー、コメント）。データはブラウザの localStorage に保存
- `tutorial.js`：6手の定跡を使った、任意で開始・再実施できる操作チュートリアル
- サンプル定跡は `app.js` の `SAMPLE_KIF` にあります
- 定跡解説ページ（`joseki/`）は `tools/joseki-data.js` を編集して `node tools/build-joseki.js` で生成します（sitemap.xml も更新）

## チュートリアル

初めて利用するブラウザでは開始案内が表示されます。「今は使ってみる」で閉じられ、ヘッダーの「チュートリアル」または「使い方」からいつでも始められます。定跡解説から特定の棋譜を開いた場合は、その棋譜の利用を優先して初回案内を出しません。

教材は四間飛車の出だし6手と、6手目を三間飛車にした分岐です。実際の盤・ツリー・暗記・KIF処理を使い、次を順番に体験します。

1. 駒を動かす
2. 手順を戻す・進める
3. 分岐を追加する
4. ツリーで局面を選び、コメントを書く
5. 「答え」を使い、先手で2つの変化を暗記する
6. 後手で暗記する
7. 両方の手を暗記する
8. 設定でコメントを隠し、めくって確認する
9. 練習用棋譜をKIFに書き出す
10. 練習用KIFを、通常と同じ読み込み画面で取り込む

体験中の棋譜はメモリ上だけで扱い、通常の棋譜保存やFirebase同期の対象にしません。終了時には元の棋譜と設定へ戻り、体験中に届いた同期更新があれば最新の保存内容を読み直します。「練習用の定跡を残して終了」を選んだ場合だけ、既存の棋譜を上書きせず追加します。開始案内の状態は棋譜とは別の `kifu-anki-tutorial-v1` に保存します。

成り・持ち駒の打ちはこの短い教材には含みません。Googleログインやバックアップの操作は「使い方」「一覧」から利用できます。

## 検証

依存パッケージのインストールは不要です。

```sh
node --check app.js
node --check tutorial.js
node tools/test-tutorial.js
```
